# Brief: SmileWorks Dental (3 สาขา)

จากคุณหมอเจ้าของคลินิก (คุยทาง LINE 12 พ.ย.)

- มี 3 สาขา: อารีย์, ทองหล่อ, บางนา ทันตแพทย์รวม 11 คน บางคนเข้าหลายสาขา
- ตอนนี้รับนัดทาง LINE OA กับโทรศัพท์ แอดมินจดลง Google Sheet วุ่นมาก คนไข้ไม่มาตามนัดราว 15%
- อยากให้คนไข้จองเองได้ทั้งเว็บและแอป เลือกสาขา หมอ บริการ เวลา
- งานจัดฟันต้องมัดจำ 1,000 บาท อยากให้จ่ายผ่าน PromptPay ตอนจอง
- เตือนนัดล่วงหน้าทาง LINE 1 วัน และให้คนไข้เลื่อนนัดเองได้
- คนไข้จัดฟันอยากเห็นตารางนัดรอบถัดไปทั้งหมด และยอดค้างชำระของแพ็กเกจจัดฟัน
- อยากมีแต้มสะสม แต่ไม่รีบ
- หลังบ้าน: ตารางหมอแต่ละสาขา, ปิดวันลา, ดูคิวรายวัน, รายงานยอดจองต่อสาขา
- อยากให้ AI ตอบแชต LINE เรื่องราคาและเวลาเปิดปิดในอนาคต
- เวชระเบียน (ฟิล์ม, chart ฟัน) ใช้โปรแกรมคลินิกเดิมชื่อ "DentCloud" อยู่ ยังไม่รู้ว่ามี API ไหม
